# codeagent-minimal 能力域与优势

> 手搓代码审查智能体：给需要审代码但不写代码的人。纯标准库零依赖。

## 一、能力域

### 1. 代码审查（核心）
- 静态分析(语法/复杂度/结构) + 可选LLM审查, 0-100分
- 缺陷根因库(known_defects 固化) + 规则反哺闭环(越用越准)

### 2. 安全扫描
- 10维度漏洞(SQL注入/反序列化/命令注入/SSRF/弱哈希/硬编码密钥/IDOR等)
- 危险函数 + 密钥模式 + 严重度分级(critical/high/medium)

### 3. 测试
- 测试选择(精确函数名) + 测试覆盖分析

### 4. 审批与权限
- 高危命令审批(细粒度权限) + 命令执行策略

### 5. 沙箱安全执行
- 进程降权沙箱 + 路径守卫(跨平台防穿越/盘符逃逸)

### 6. 会话与上下文
- 上下文压缩(预算裁剪)；会话持久化/resume 为**待定(pending)不入库**，运行时不可达

### 7. 模型降级链
- 本地↔云端切换 + 本地优先(数据不出厂)

### 8. 领域审查
- 原子化断链(跨仓库import/依赖拓扑) + 本体数据质量 + 工业阀门规则 + 极简风格

## 二、优势

### 1. 纯标准库零依赖
- 零第三方依赖, 轻量可独立部署(无venv/无pip install)
→ 契合中小企业工厂(怕大部署/依赖)

### 2. 本地独立 + 数据不出厂
- 全本地运行, 代码/数据不出厂
→ 契合工厂/甲方安全诉求(核心卖点)

### 3. 原子化可组装
- 29原子(审查/安全/测试/审批/沙箱/降级/领域审查…), 加壳可组装, 按需取模块
→ 极简可用 + 灵活扩展

### 4. 代码审查/安全/测试深度
- 深度审查/安全扫描/测试(竞品如Codex/Claude Code不专精)
→ 差异化优势(专注代码质量)

### 5. 极简不炫技
- 手搓/极简/可独立部署(契合"给审代码但不写代码的人")
→ 门槛低, 中小企业工厂可落地

## 三、定位一句话
```
给需要审代码但不写代码的人: 本地极简代码审查/安全/测试智能体,
纯标准库零依赖, 数据不出厂, 原子化可组装, 中小企业工厂代码工具
```

# CodeAgent Minimal — 别急着装全家桶，先把手搓的这一个用起来

> 给「需要审代码、但不写代码的人」的本地极简代码审查 / 安全 / 测试智能体。
> 纯标准库零依赖，数据不出厂，原子化可组装。

## 一、场景：你一定遇到过这些时刻

你是工厂的技术负责人、是甲方验收的工程师、是团队里那个「代码最后把关」的人。
你不一定天天写代码，但你躲不过一件事——**你签的字，代码得能跑、得安全、得经得住别人挑**。

然后你看到一段代码：

- 它藏着 SQL 注入，没人发现；
- 它写了一百行 if-else，圈复杂度爆炸，三个月后没人敢改；
- 它依赖了一个带漏洞的包，供应商说「没事」，你说「我不放心」；
- 你想把它交出去，但代码是**工厂的资产、甲方的数据**——你不敢传上网，也不敢装一堆工具链。

于是你打开 GitHub，搜「代码审查工具」，跳出来的全是：

- 要配环境、要 `pip install` 一堆依赖、要 Docker、要 GPU、要云端 key；
- 动辄几百 MB、几十个组件，装完就让你头疼；
- 有的还是「给你写代码」的 Agent，动不动就自己动手改你的代码——可你只想要**有人帮你把把关**，不是抢你键盘。

**折腾半天，你只想干一件事：把代码看一遍，挑出问题，心里有底。**

## 二、它是什么：一句话说清楚

```
给需要审代码但不写代码的人：本地极简代码审查 / 安全 / 测试智能体，
纯标准库零依赖，数据不出厂，原子化可组装，中小企业工厂代码工具。
```

它不是又一个「帮你写代码」的大模型全家桶。
它是**一个守在门口、帮你看代码质量的人**：

- 你说 `python codeagent.py review file.py`，它就把一个文件审查一遍，打分、揪漏洞；
- 你说 `python codeagent.py guard target/`，它就把审查、安全扫描、模糊测试串成一条链，一键把关键部位过一遍；
- 它不写代码、不抢键盘，它只**看**、只**报**、只在你的授权下执行。

## 三、方法论：为什么是「极简 + 本地 + 原子化」

### 1. 纯标准库，零依赖——敢下就能跑

没有任何第三方依赖，不用 `pip install`，不用 Docker，不用配 venv。
Python 3.8+ 自带的东西就够它跑了。

> 对一个「怕大部署、怕依赖地狱」的中小工厂/甲方来说，**「敢下就能跑」**就是最大的门槛被拆掉了。
> 你不需要一个运维团队来养一个审查工具。

### 2. 本地运行，数据不出厂——核心卖点

默认全本地处理，代码、数据不出你的机器。
云端 LLM、远端漏洞库（OSV）都要你显式 `--remote / --osv / --llm` 才会开启。

> 对工厂、对甲方来说，代码和业务数据是**命根子**。
> 一个「默认不联网、默认不出厂」的审查工具，才敢放心签。

### 3. 原子化可组装——按需取用，不捆绑

29+ 个原子能力（审查 / 安全 / 测试 / 审批 / 沙箱 / 会话 / 模型降级 / 领域审查…）都可以独立跑、任意拼。
你只要审查就只跑审查，要安全就加个安全扫描，要更稳就拼上测试。

> 极简可用 + 灵活扩展，两全其美：**轻得起来，也重得上去。**

### 4. 深度做审查 / 安全 / 测试——把一件事做透

很多编码 Agent（Codex / Claude Code 之类）擅长「写」，但不专精「审」。
我们把力气花在**审查、安全扫描、测试**这一件事上：静态分析 + 可选 LLM 审查 + 0–100 打分 + 缺陷根因库（越用越准）+ 规则反哺闭环。

> 不做大而全的「编码全家桶」，做小而专的「质量守门员」。

### 5. 极简不炫技——为「不写代码的人」设计

手搓、极简、可独立部署、命令一看就懂。
门槛低到工厂里管质量的工程师也能直接上手。

## 四、诚实边界：它不是什么

把话说清楚，才敢放心用。CodeAgent Minimal **不是**：

- ❌ **不是**帮你写代码的大模型 IDE / Agent —— 它不替你写代码、不抢你键盘，只做审查、安全、测试；
- ❌ **不是**大而全的企业级全家桶 —— 它是**轻量内核**，重型编排（assembler / orchestrator / CodeMode）是闭源的、在独立工作区，不随本仓库分发、也不链接；
- ❌ **不是**联网 / 云端智能体 —— 默认数据不出厂，云端能力需显式开启；
- ❌ **不是**对大型分布式系统的全套深度验证 —— 它是本地代码级的质量审查、安全扫描与测试，覆盖中小项目与关键模块的日常把关；
- ❌ **不是**零成本维护的银弹 —— 仍需你会跑一条 Python 命令、能读懂它报出来的问题。

**它的定位是：** 轻、本地、够用、诚实——给「需要把关但不写代码的人」一个敢下敢用的本地代码质量守门员。**它不是大编码，它是大门卫。**

## 五、怎么上手（30 秒）

```bash
git clone git@github.com:zhengjinjun1975/codeagent-minimal.git
cd codeagent-minimal

# 1. 审查一个文件
python codeagent.py review sample_target.py

# 2. 跑测试 harness
python codeagent.py test sample_target.py

# 3. 依赖漏洞 + 污点扫描
python codeagent.py dep-scan .

# 4. 一键安全·质量组装链
python codeagent.py guard sample_target.py
```

零第三方依赖，一条命令审查代码质量。干净文件给分，有问题的文件直接揪出漏洞。
